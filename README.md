# Отчёт по лабораторной работе №1 (ЛОИС)

Проект подготовлен для компиляции **XeLaTeX** в VS Code / LaTeX Workshop или другом LaTeX-редакторе.

## Состав

- `report.tex` — исходник отчёта, редактируемый LaTeX.
- `figures/` — восемь схем **только в формате PNG**, извлечённых из предоставленного архива; `.drawio` не включены.
- `report.pdf` — проверенная собранная версия.

## Сборка

Из каталога проекта:

```bash
xelatex report.tex
xelatex report.tex
```

Схемы подключаются непосредственно через `\includegraphics` из `figures/`.

## Автор

Сайковский А.В., группа 421702. Личный вклад: реализация max-min композиции и механизма прямого нечёткого вывода. Данные заполнены в `report.tex`.

## Содержание

Титульный лист, тема/цель/задание, теория, формат базы знаний, структуры и функции программы, 8 блок-схем, демонстрация на трёх наборах данных, контроль корректности ввода, шесть контрольных вопросов, личный вклад, вывод, источники.

В контрольных вопросах даны математически уточнённые ответы относительно формулы импликации Гёделя и max-min композиции: это намеренно исправляет слишком сильные утверждения в старом образце отчёта.

**Примечание:** в предоставленном архиве отсутствовали PNG-схемы функций `read_knowledge_base()` и `format_fuzzy_set()`; они описаны текстом без добавления выдуманных схем. Это соответствует предыдущему запросу не создавать эти схемы.
