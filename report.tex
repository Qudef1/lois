\noindent Тема: Программирование операций обработки и преобразования формул прикладных и неклассических логик.

\noindent Цель: Приобрести навыки программирования алгоритмов обработки данных в неклассических логических моделях решения задач.

\noindent Задание: Реализовать прямой нечёткий логический вывод с использованием треугольной нормы $\min$ и нечёткой импликации Гёделя.

\reportheading{Описание работы}
Разработана программа на языке Python, выполняющая прямой нечёткий логический вывод по фактам и правилам из текстового файла. Факты задаются конечными нечёткими множествами, а правила имеют форму \texttt{A(x) \textasciitilde > B(y)} (в файле фактически используется слитная запись \texttt{\textasciitilde>}). Для каждого применимого правила строится нечёткое бинарное отношение по импликации Гёделя, после чего вычисляется max-min композиция с входным фактом. Новые факты добавляются в базу до прекращения её расширения.

При реализации использованы стандартные средства Python, модули \texttt{re} и \texttt{pathlib}, списки, кортежи, множества и словари. Совместимость фактов определяется совпадением наборов элементов их универсумов. Уже известные результаты обнаруживаются сравнением списков пар, поэтому при таком сравнении учитывается порядок элементов. Предполагается, что входные степени принадлежности находятся в диапазоне $[0,1]$, а элементы внутри множества не повторяютсяю.

\reportheading{Теоретические сведения}
Нечёткое множество $A$ на универсуме $X$ определяется функцией принадлежности $\mu_A:X\to[0,1]$. Значение $\mu_A(x)$ задаёт степень принадлежности элемента $x$ множеству $A$. Для конечного универсума множество записывается в виде
\begin{equation}
 A=\{\langle x_1,\mu_A(x_1)\rangle,\ldots,\langle x_n,\mu_A(x_n)\rangle\}.
\end{equation}

Нечёткий предикат --- предикат, истинностное значение которого принадлежит $[0,1]$. Нормальным называется нечёткое множество высоты $h(A)=1$, где $h(A)=\sup_x\mu_A(x)$. Если $h(A)<1$, множество является субнормальным.

Треугольная норма (t-норма) --- бинарная операция на $[0,1]$, обобщающая нечеткую конъюнкцию. В данной работе используется
\begin{equation}
 T(a,b)=\min(a,b).
\end{equation}

Импликация Гёделя задаётся выражением
\begin{equation}
 I_G(a,b)=
 \begin{cases}
  1, & a\leq b,\\
  b, & a>b.
 \end{cases}
 \label{eq:godel}
\end{equation}

Нечёткое бинарное отношение, соответствующее правилу $A(x)\to B(y)$, определяется на $X\times Y$ следующим образом:
\begin{equation}
 R(x,y)=I_G\bigl(\mu_A(x),\mu_B(y)\bigr).
 \label{eq:relation}
\end{equation}

Обобщённый modus ponens позволяет по входному факту $A'(x)$ и правилу $A(x)\to B(y)$ получить новое заключение $B'(y)$. Используется max-min композиция, которая на конечном универсуме принимает вид
\begin{equation}
 \boxed{\mu_{B'}(y)=\max_{x\in X}\min\bigl(\mu_{A'}(x),R(x,y)\bigr).}
 \label{eq:composition}
\end{equation}

Прямой нечёткий вывод --- последовательное получение новых фактов из уже имеющихся фактов и нечётких правил. Результат каждого шага может использоваться в последующих шагах. Обход правил повторяется, пока количество различных фактов в базе не перестанет увеличиваться.

\reportheading{Структуры данных и функции программы}
Словарь \texttt{facts} сопоставляет имени нечёткого множества список пар \texttt{(element, degree)}. Список \texttt{rules} хранит пары имён посылки и заключения. Бинарное нечёткое отношение представляется списком троек \texttt{(x, y, implication\_degree)}.

\begin{itemize}
\item \texttt{read\_knowledge\_base(filename)} --- считывает факты и правила с помощью регулярных выражений и преобразует степени принадлежности в числа;
\item \texttt{build\_godel\_relation(antecedent, consequent)} --- строит отношение по формуле~\eqref{eq:godel};
\item \texttt{max\_min\_composition(observation, relation)} --- вычисляет заключение по формуле~\eqref{eq:composition};
\item \texttt{apply\_fuzzy\_rule(...)} --- выполняет один шаг нечёткого вывода;
\item \texttt{find\_compatible\_facts(...)} --- находит факты, имеющие тот же набор элементов, что и посылка;
\item \texttt{format\_fuzzy\_set(...)} --- создаёт текстовую запись множества для вывода;
\item \texttt{forward\_fuzzy\_inference(...)} --- организует полный прямой вывод до отсутствия новых фактов;
\item \texttt{main()} --- запускает считывание и выводит результаты.
\end{itemize}

import re
from pathlib import Path


NAME_PATTERN = r"[A-Za-z][A-Za-z0-9]?"
FACT_PATTERN = re.compile(
    rf"^[ \t]*({NAME_PATTERN})[ \t]*=[ \t]*\{{([^}}\r\n]+)\}}[ \t]*\r?$",
    re.MULTILINE,
)
PAIR_PATTERN = re.compile(r"<([^,>]+),\s*((?:0|1(?:\.0+)?|0?\.\d+))>")
RULE_PATTERN = re.compile(
    rf"^[ \t]*({NAME_PATTERN})(?:\([^()\r\n]*\))?[ \t]*~>[ \t]*"
    rf"({NAME_PATTERN})(?:\([^()\r\n]*\))?[ \t]*\r?$",
    re.MULTILINE,
)


def build_godel_relation(antecedent, consequent):
    """Построить R(x, y) = I_G(A(x), B(y))."""
    relation = []
    for x, a_degree in antecedent:
        for y, b_degree in consequent:
            implication_degree = b_degree if a_degree > b_degree else 1.0
            relation.append((x, y, implication_degree))
    return relation


def max_min_composition(observation, relation):
    """Вычислить B'(y) = max_x min(A'(x), R(x, y))."""
    output_degrees = {}
    for x, observed_degree in observation:
        for source_x, y, relation_degree in relation:
            if x != source_x:
                continue
            candidate_degree = min(observed_degree, relation_degree)
            if y not in output_degrees or candidate_degree > output_degrees[y]:
                output_degrees[y] = candidate_degree
    return list(output_degrees.items())


def apply_fuzzy_rule(antecedent, consequent, observation):
    """Один шаг обобщённого modus ponens."""
    relation = build_godel_relation(antecedent, consequent)
    return max_min_composition(observation, relation)


def find_compatible_facts(antecedent, facts):
    """Факты, определённые на том же наборе элементов, что и посылка."""
    antecedent_domain = {element for element, _ in antecedent}
    compatible = {}
    for fact_name, memberships in facts.items():
        fact_domain = {element for element, _ in memberships}
        if fact_domain == antecedent_domain:
            compatible[fact_name] = memberships
    return compatible


def format_fuzzy_set(memberships):
    """Сохранить первоначальный формат печати результата."""
    return "{" + ",".join(f"<{element}, {degree}>" for element, degree in memberships) + "}"


def forward_fuzzy_inference(rules, facts):
    """Применять правила, пока база фактов не перестанет расширяться."""
    derivation_lines = []
    already_reported = []

    while True:
        facts_before_pass = len(facts)
        for antecedent_name, consequent_name in rules:
            antecedent = facts[antecedent_name]
            consequent = facts[consequent_name]
            suitable_observations = find_compatible_facts(antecedent, facts)

            for observed_name, observation in suitable_observations.items():
                derived_fact = apply_fuzzy_rule(antecedent, consequent, observation)
                derived_name = f"_{len(derivation_lines) + 1}"
                line = (
                    f"{{{observed_name}, {antecedent_name}(x)~>{consequent_name}(y)}} "
                    f"|~ {derived_name} = {format_fuzzy_set(derived_fact)}"
                )

                # Повтор уже известного исходного факта показываем один раз.
                if derived_fact in facts.values():
                    if derived_fact not in already_reported:
                        derivation_lines.append(line)
                        already_reported.append(derived_fact)
                    continue

                derivation_lines.append(line)
                facts[derived_name] = derived_fact
                already_reported.append(derived_fact)

        if len(facts) == facts_before_pass:
            break

    return "\n".join(derivation_lines)


def read_knowledge_base(filename):
    """Прочитать факты и правила из текстовой базы знаний."""
    content = Path(filename).read_text(encoding="utf-8")
    facts = {}
    rules = []

    for match in FACT_PATTERN.finditer(content):
        fact_name = match.group(1)
        body = match.group(2)
        elements = PAIR_PATTERN.findall(body)
        if body.count("<") != len(elements):
            raise ValueError(
                f"Степени принадлежности в факте {fact_name} "
                f"должны быть в диапазоне [0.0, 1.0]: {match.group(0).strip()}"
            )
        facts[fact_name] = [(item.strip(), float(degree)) for item, degree in elements]

    for match in RULE_PATTERN.finditer(content):
        rules.append((match.group(1), match.group(2)))

    return facts, rules

    print(forward_fuzzy_inference(rules, facts))
