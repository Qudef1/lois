# Лабораторная работа 4

Весь новый код — **один файл [lab4.py](../lab4.py), 119 строк вместе с комментариями**.
Он напрямую импортирует из `lab1.py` чтение базы, построение отношения Гёделя,
max-min композицию и форматирование множеств.

Предыдущие модули сохранены отдельно в `archive/lab4_backup/`.

Запуск из корня проекта:

```powershell
python lab4.py
python lab4.py lab4/examples/input3.txt
```

Без аргумента используется `lab4/input.txt`. Нужен только Python, без сторонних библиотек.

Входной файл записывается в формате первой лабы. `C` — известное следствие:

```text
A = {<x1, 0.3>, <x2, 0.8>}
B = {<y1, 0.4>, <y2, 0.7>}
C = {<y1, 0.4>, <y2, 0.7>}

A(x) ~> B(y)
```

Если правило отсутствует, каждый факт кроме `C` задаёт строку отношения:

```text
X1 = {<y1, 1.0>}
X2 = {<y1, 1.0>}
C = {<y1, 0.5>}
```

Программа вычисляет верхнюю границу и проверяет её прямым выводом. Если решение
есть, находит все минимальные посылки и печатает объединение областей `[lower, upper]`.
`x` означает декартово произведение, `UNION` — объединение. При превышении
10 000 кандидатов программа сообщает, что полное множество не вычислено.
Степени представлены обычными `float`, как в первой лабораторной.

- `examples/input1.txt`–`input7.txt` — семь проверенных входных файлов.
- `results/input1.txt`–`input7.txt` — фактические результаты.
- `figures/drawio/*.drawio` — четыре редактируемые схемы по образцу первой лабы.
- `figures/*.png` — соответствующие изображения для отчёта.
- `report.tex`, `report_lab4.pdf` — отчёт с теми же разделами и оформлением, что первая лаба.

Схемы открываются в draw.io / diagrams.net. После правки экспортируйте PNG
в `lab4/figures/` с тем же именем, что у исходника, например `lab4_main.png`.

Сборка отчёта из корня проекта, два раза для ссылок:

```powershell
xelatex -jobname=report_lab4 -output-directory=lab4 lab4/report.tex
xelatex -jobname=report_lab4 -output-directory=lab4 lab4/report.tex
```

Из папки `lab4` можно выполнить `xelatex -jobname=report_lab4 report.tex` дважды.
Для сборки нужны XeLaTeX и те же шрифты, что в первой лабораторной.
